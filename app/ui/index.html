Freeplay

A game trainer for Windows. Free, open source, no account needed.

It finds your installed games, attaches to one and turns on cheats. Tables other people have published arrive on their own. If nobody has written one for your game, import a Cheat Engine .CT file or search the game's memory and make one.

The only request it makes is for the table list, and you can turn that off. No telemetry.

It will not attach to anything running an anti-cheat, so it is single player only.
