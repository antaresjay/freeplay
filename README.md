# Freeplay

An open source game trainer for Windows. Find values in a running single
player game, freeze them, patch them, and save what you found as a table
anyone else can use.

Named after the arcade cabinet setting that gives you unlimited credits
without feeding coins into the slot.

> Early development. Nothing to install yet.

## Scope

Single player and offline games only. Freeplay refuses to attach to any
process running an anti-cheat, and that check is in the code rather than in a
disclaimer. Cheating in multiplayer ruins other people's games and gets
accounts banned.
